# Glossary

도메인 용어. 새 용어는 여기 먼저 추가한다.

| 용어 | 설명 |
|------|------|
| RUDP | Reliable UDP. LiteNetLib 기반 신뢰성 전송 |
| IOCP | Windows I/O Completion Port. 고성능 TCP 서버에 사용 |
| Session | 연결 단위의 송수신·수명 주기 추상화 |
| Shared | 클라이언트/서버가 공유하는 타입·계약 어셈블리 |

## 공통 (DS 스택)

| 용어 | 설명 |
|------|------|
| netstandard2.1 | Unity 및 다중 .NET 런타임 호환 타깃 |
| NuGet | 패키지 배포 단위 |
| Sandbox / Examples | 샘플·데모 프로젝트 |
